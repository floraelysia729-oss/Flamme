# Flamme — 竞赛产品设计文档

> 日期：2026年5月24日
> 赛事：南京大学 2025 级交互组程序设计大赛（创意赛道）
> 团队：全栈独立开发，设计能力一般

---

## 1. 产品定位

**一句话：** Flamme — 你的知识会自己长出来的个人知识系统。

**30 秒答辩开场：**
> "1945 年，Vannevar Bush 设想了一台叫 Memex 的机器——个人的、互相关联的知识存储。80 年来没人解决一个问题：谁来维护？LLM 给出了答案。Flamme 是一个 Web 应用：你扔进课程资料，它自动提取概念、建立关联、可视化成一张会生长的知识网。"

**比赛定位：**
- 主赛道：智慧校园类（课程知识自动组织）
- 复用赛道：AI 智能体创新专项组

**核心差异（对竞品）：**
竞品（类 NotebookLM）预置 40+ 南大教材，是被动消费知识。Flamme 基于用户自己的所有资料构建个人知识图谱，是主动建造知识。竞品给每个人相同的内容，Flamme 给每个人独一无二的知识结构。

## 2. 产品形态

| 组成 | 角色 | 说明 |
|------|------|------|
| **Web/PWA** | 主产品 | 苹果风格 UI，打开即用，评委零门槛体验 |
| **Obsidian 插件** | 加分项 | 已实现，展示工程完整度和生态扩展能力 |
| **Python 后端** | 核心 | 已有 FastAPI 后端，LLM 调用 / 图谱 / 向量检索 |

### 设计语言

- **苹果风格**：大量留白、圆角卡片、系统字体（-apple-system / Inter）
- **配色**：浅色主题为主，中性色 + 单一强调色
- **图标**：Lucide（SF Symbols 风格线条图标）
- **像素火苗**：品牌签名元素，出现在 logo、处理动画、空状态三处

## 3. 三个主视图

底部 tab 导航，苹果风格极简三栏。

### 3.1 图谱视图（首页 / Hero）

打开 app 看到的第一个界面。

**核心交互：**
- 拖拽、缩放知识图谱
- 点击节点 → 侧滑面板弹出结构化学习卡片
- 双击节点 → 进入对话（"给我讲讲这个"）
- 右上角"盲区发现"图标（闪烁提示有新盲区）
- 对话回答时，相关实体在图谱上高亮，推理路径动画描线

**导入流程：**
- 拖入文件 → 像素火苗处理动画 → "正在解析..." → "发现 N 个概念" → 节点从中心向外生长 → 完成

**空状态：**
- 空白画布 + 中心像素火苗微微跳动 + [+] "拖入你的第一份资料"

**图谱库选型：** D3 force-directed 或 react-force-graph

### 3.2 活跃视图

GitHub 贡献热力图风格，展示学习活动。

**内容：**
- **热力图**：每格 = 一天，颜色深浅 = 当天新增概念/关系数量
- **每日列表**：点击某天，展示那天新增的实体和来源文件
- **统计摘要**：本周新增 N 个概念 · M 份资料
- **间隔重复待复习列表**：基于 SM-2 算法，"今天该复习的概念"

**情感锚点：** "你的学习有痕迹" — 类似 GitHub 的成就感驱动。

### 3.3 对话视图

围绕知识上下文的对话，不是通用聊天室。

**功能：**
- 基于 RAG 的问答，回答标注来源（哪份资料第几页）
- 苏格拉底提问模式：基于用户图谱盲区出题，不是通用教材提问
- 从图谱节点进入时，对话自动绑定该节点上下文
- 回答时图谱联动：提到的概念在图谱上高亮

**苏格拉底提问差异化：**
- 竞品："请解释什么是过拟合。"（通用，所有人被问一样的）
- Flamme："你笔记里记了过拟合和正则化，但没连接到 dropout。你觉得 dropout 是怎么解决过拟合的？"（基于个人图谱盲区）

## 4. 图谱节点学习卡片

点击节点弹出侧滑面板，展示 NovaForge 风格的结构化学习笔记。

**板块（根据资料内容自动生成，缺的板块 = 盲区提示）：**

| 板块 | 内容 | 说明 |
|------|------|------|
| 概念 | 核心定义与直觉理解 | 从资料中提取 |
| 核心 | 关键公式 / 定理 | 数学内容框展示 |
| 方法速通 | 解题技巧、对比总结 | 如 ID3 vs C4.5 vs CART |
| 来源 | 标注来自哪份资料哪一页 | 可追溯 |
| 盲区 | 缺少的关联节点提示 | "缺少与「集成学习」的连接" |
| 关联节点 | 相连实体列表 | 可点击跳转 |

**生成方式：** 后端 LLM 在实体提取阶段生成，存入 SQLite，前端渲染。

## 5. 四个核心能力

只有个人知识图谱才能做到的事，竞品无法复制。

### 5.1 苏格拉底提问

- **触发：** 对话中主动提问 / 图谱节点"考考我"按钮
- **原理：** 扫描用户图谱中该节点的连接和盲区，针对性出题
- **示例：** "你学了 dropout 和 L2 正则化，但它们在你的图谱里是断开的。你觉得它们解决的是同一个问题吗？"
- **评委 wow 点：** AI 不是在念答案，是在教

### 5.2 知识盲区发现

- **触发：** 图谱视图右上角，图标闪烁提示
- **原理：** 分析图谱弱连接 / 孤立簇 / 缺失边，LLM 判断哪些应该连但没连
- **展示：** 虚线标出"可能的缺失连接"，用户可点击确认或忽略
- **评委 wow 点：** "它知道我哪里没学到"

### 5.3 间隔重复提醒

- **触发：** 活跃视图的待复习列表
- **原理：** 每个实体记录最后复习时间和复习次数，SM-2 算法计算下次复习时间
- **展示：** 活跃日历标记待复习；"今天该复习的概念"列表
- **评委 wow 点：** 知识图谱 + 记忆曲线 = 不只是整理，还帮你记住

### 5.4 图谱动画演示

- **触发：** 对话回答时自动播放 / 手动触发
- **原理：** 回答涉及的实体高亮，推理路径动画描线
- **展示：** 问"决策树和随机森林什么关系？" → 决策树→集成学习→随机森林 路径亮起
- **评委 wow 点：** 看见 AI 在你的知识里"走"

## 6. 像素火苗品牌元素

三处出现，不与苹果风格 UI 冲突：

| 位置 | 作用 | 时机 |
|------|------|------|
| 导航栏 logo | 品牌识别 | 常驻 |
| 处理动画 | 功能反馈 | 导入资料处理中 |
| 空状态 | 情感引导 | 无资料时画布中央 |

像素火苗是品牌签名，苹果风是舞台。不混搭，并列。

## 7. 技术架构

```
┌─────────────────────────────────────────────┐
│  Web/PWA 前端（新）                          │
│  React / Svelte  ·  D3 图谱  ·  苹果风 UI    │
└──────────────────┬──────────────────────────┘
                   │ HTTP / SSE
┌──────────────────▼──────────────────────────┐
│  FastAPI 后端（已有，扩展）                   │
│  ├─ 文档解析（PDF/PPT/Word → Markdown）      │
│  ├─ 实体提取 + 结构化笔记生成（LLM）          │
│  ├─ 关系构建（知识图谱 → SQLite）             │
│  ├─ 向量索引（语义检索）                      │
│  ├─ RAG 对话 + 苏格拉底提问                   │
│  ├─ 盲区发现（图谱分析 + LLM）                │
│  └─ 间隔重复（SM-2 算法）                    │
└──────────────────┬──────────────────────────┘
                   │ API 调用
         DeepSeek / DashScope / MinerU
```

**后端已有能力（可直接复用）：**
- 文档解析管线（pdf_parser, markdown_parser）
- 实体提取（agent + LLM）
- 知识图谱（SQLite graph_store）
- 向量索引（embedding_store）
- RAG 对话（chat routes + agent orchestration）
- 文件同步（sync）

**需要新增：**
- 苏格拉底提问 agent prompt
- 盲区发现算法（图谱分析 + LLM 判断）
- 间隔重复算法（SM-2）+ 实体复习时间追踪
- 结构化笔记生成 prompt（NovaForge 7 步风格）
- 图谱动画数据接口（路径高亮）
- Web 前端（全新）

## 8. Demo 流程（答辩用）

**总时长约 3 分钟：**

| 时间 | 动作 | 评委看到什么 |
|------|------|-------------|
| 0-10s | 打开 app，空状态 | 像素火苗跳动，"拖入你的第一份资料" |
| 10-30s | 拖入 3 份课件 PDF | 火苗动画 → "正在解析..." → 概念逐个淡入 |
| 30-60s | 图谱生长完成 | 节点从中心向外展开，连线绘制，完整图谱呈现 |
| 60-90s | 点击"决策树"节点 | 侧滑面板弹出结构化笔记：概念、公式、来源 |
| 90-120s | 点击"考考我" | 苏格拉底提问："你学了 X 和 Y 但没连 Z，你觉得..." |
| 120-150s | 切到活跃日历 | 热力图 + "今天该复习 5 个概念" |
| 150-180s | 盲区发现 | 图谱上虚线提示缺失连接，点击确认后连线出现 |

## 9. 竞品对比话术

| 维度 | 竞品（类 NotebookLM） | Flamme |
|------|----------------------|--------|
| 知识来源 | 预置 40+ 教材 | 你自己的所有资料 |
| 学习模式 | 被动消费 | 主动建造 |
| 可视化 | 思维导图（树状） | 知识图谱（网状） |
| 发现盲区 | 无 | 图谱分析自动发现 |
| 记忆巩固 | 无 | 间隔重复提醒 |
| 跨课程关联 | 无（教材独立处理） | 自动发现意外连接 |
| 个性化 | 所有人相同 | 每个人的图谱独一无二 |

**关键句：** "有个产品帮你们读了南大所有教材。很好，但那是在帮你消费知识。我们做的是另一件事：让你拥有自己的知识结构。"

## 10. 里程碑

1. **Web 前端骨架**：三视图路由 + 基础 UI + 图谱渲染
2. **导入流程**：拖入文件 → 后端处理 → 图谱节点出现
3. **节点卡片**：点击节点 → 结构化学习笔记
4. **对话 + 苏格拉底**：对话视图 + 基于盲区的提问
5. **活跃日历 + 间隔重复**：热力图 + 待复习列表
6. **盲区发现**：图谱分析 + 虚线提示
7. **图谱动画**：对话联动 + 路径高亮
8. **像素火苗**：logo + 处理动画 + 空状态
9. **Demo 打磨**：数据准备 + 演示脚本 + PPT
